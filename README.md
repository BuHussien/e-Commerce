
# 🛍️ E-Commerce

A modern and responsive e-commerce application built with React, TypeScript, Redux Toolkit, and Tailwind CSS.

## 🚀 Features

- Authentication (Login & Register)
- Product Browsing
- Shopping Cart
- Wishlist
- Checkout & Orders
- Account Profile
- Address Management
- Security Settings
- Responsive Design

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Redux Toolkit
- React Router
- Axios
- Tailwind CSS

## ⚙️ Installation

```bash
git clone https://github.com/BuHussien/e-Commerce.git
cd e-Commerce
npm install
npm run dev
```
